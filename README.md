# INOVATECH

## Sobre o projeto

O **GatherVent** é um sistema web desenvolvido com o objetivo de facilitar a organização, divulgação e gerenciamento de eventos.

A plataforma permite que usuários criem eventos, realizem inscrições, participem de salas e interajam com outros participantes.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- EJS
- Firebase

## Funcionalidades

- Cadastro e login de usuários
- Criação e visualização de eventos
- Inscrição em eventos
- Criação e participação em salas
- Visualização de perfis de usuários
- Gerenciamento de participantes

## Objetivo

Oferecer uma plataforma simples e prática para conectar pessoas e facilitar a organização de eventos.
